# 调试与测试手册

## 1. 本地调试
- 使用 `-headless=false` 观察浏览器行为
- 调整端口/下载目录/语言与字体（见 `browser` 封装）
- 使用 MCP Inspector 验证工具链是否可用

## 2. 日志与断点
- 日志：`logrus` 等级控制，关键字段（方法、路径、账号、耗时、错误）
- 断点：入口 handlers → service → actions → browser 逐层定位

## 3. 集成测试策略
- 对 `xiaohongshu/*` 行为做可回放：固定输入、断言页面状态变化
- 尽量减少外部依赖，优先使用本地图片/视频路径

## 4. API 验证
- 参考 `docs/API.md` 以及 README 内的 curl 示例进行快速验证

## 5. 常见问题
- 登录态丢失、二维码过期、被“踢下线”、图片路径错误、端口占用等 → 见 `docs/faq.md`

## 6. 排错清单
- 确认已登录且 cookies 已加载
- 使用非无头模式观察是否卡在上传/提交步骤
- 检查标题/正文长度是否合规（20/1000）
- 图片/视频文件是否存在且可读
- 网络代理/防火墙是否影响请求
